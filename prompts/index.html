파일 붙이는 법

  • 끌어다 놓기 · PDF, 사진, 캡처를 Code 탭 입력창에 끌어다 놓습니다. 입력창의 + 단추로 골라도 됩니다.
  • 작업 폴더에 넣기 · 파일을 작업 폴더에 복사하고 “폴더의 사회_3차시.pdf를 읽어 줘”처럼 이름을 말합니다. 입력창에 @를 치면 폴더 안 파일 이름이 뜹니다.
  • 큰 파일 · 교과서·지도서 전체보다 그 단원 쪽만 잘라서 붙이면 빠르고 정확합니다. 손글씨 스캔도 읽습니다.
  • 화면 캡처는 Snipaste · snipaste.com에서 받아 둡니다. F1을 눌러 영역을 고르고, 네모 상자를 그리고, 글자를 써 넣은 뒤 Ctrl+C로 복사해서 입력창에 Ctrl+V. 캡처 안에 “여기 크게”라고 써 두면 말로 설명할 것이 줄어듭니다.
